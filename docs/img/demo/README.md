## 05 项：界面仍缺，但已有结果旁证

复问卡的**界面**还是没截到。触发条件是**通话满 5 分钟**，造这个状态有两条路：

1. 在模拟器上真打满 5 分钟 —— 需要有人陪着通话 5 分钟，当时没录；
2. 改代码把阈值临时调成 5 秒 —— 改完必须改回来，且截出来的图和线上行为不一致，属于造假，不做。

现有的 `f_27.png`（`D:/华为ict/`）是同一场景的**顶部提示条**版本
（「这通电话聊太久了 / 号码不认识·正在叫女儿打给您」），
**不是** 11-07 定稿要求的居中复问卡（含 [认识][不认识] 与红框警示），两者不能互相顶替。

**但 09 这张改变了它"全无证据"的状态**：`09-child-call-list-5min-recheck.png` 里 21:46 那条
「妈妈确认通话对方为熟人（通话已超过 5 分钟）…妈妈选择了"认识"」，
说明**复问卡在 2026-11-17 那次模拟器回归里确实触发过、用户确实做出过选择、结果也确实推到了子女端**。
所以准确表述是：**功能跑通过并有子女端留痕，缺的只是老人端那张卡片本身的截图**。
被问到时这么说，不要再说"没做/没测"。

**补法**（不需要连电脑）：真机拨一通陌生号，等满 5 分钟，用**另一台手机对着屏幕拍**——
`docs/img/realdevice/` 里那 4 张就是这么拍到的。一张即可真正补齐。
