# 评估缓存复核（2026-11-20）

> 复核对象：同学乙 11-19 全量评估（Fraud-R1 中文 1,070 条 + 正常 9 条）的
> **服务端原始响应缓存** `eval-cache-2026-11-19.zip`（1,089 个 json，2.1MB）。
> 复核目的：不依赖乙的结果文件，直接用服务端原始响应验证「判定 → 推送」这条链路的正确性。

---

## 一、为什么这份缓存比结果文件更可信

| 文件 | 层次 | 里面有什么 |
|---|---|---|
| `result-2026-11-19-final.json` | 客户端整理后 | 每条样本的 `pred_*`、`topStage`、耗时 |
| `eval-cache-*.zip` | **服务端原始响应** | 服务端真正返回的 `stage`、`localStage`、`localScore`、`hits`、`isFraud`、`alert`、`meta.tokens` |

缓存是**脚本发起 HTTP 请求后，服务端返回什么就存什么**，中间没有经过任何加工。
所以它能回答一个结果文件回答不了的问题：**「推送」这个动作，服务端到底有没有做。**

---

## 二、核心结论：判定与推送的对应关系，1,089 条零例外

| 融合后 `stage` | 服务端是否生成告警（`raw.alert`） | 告警级别 | 条数 |
|---|---|---|---|
| 0 | 无 | — | 151 |
| 1 | 无 | — | 206 |
| 2 | 无 | — | 136 |
| 3 | **有** | `high` | 51 |
| 4 | **有** | `block` | 545 |

**没有任何一条 `stage <= 2` 被推送，也没有任何一条 `stage >= 3` 被漏推。**

这一条的意义：报告里「推送层 601 条」这个数最容易被追问「凭什么说推了」。
现在有了服务端响应级别的证据——不是脚本自己判的，是服务端返回了 `alert` 对象。

同时它也验证了**分级打扰**的设计是真的在跑：`S4 → block`（红屏拦截）、`S3 → high`（提醒），
而不是笼统地"判到就推"。

## 五、与乙报告数字的差异（0.8%，需以 result 文件为准）

| 项 | 缓存按文件统计 | 乙按样本统计 | 差 |
|---|---|---|---|
| 总条数 | 1,089 | 1,079 | +10 |
| `stage >= 3` | 596 | 601 | **-5** |
| `stage >= 1` | 938 | 955 | -17 |

**原因**：缓存是「一次 HTTP 请求一个文件」，评估中存在 8 条超时样本的并发 1 补跑，
补跑会产生新的缓存文件（同一条短信、新的 `alert.id`，哈希不同）；另有 2 条评估前试跑。
所以按文件统计会与按样本统计有偏差。

**结论**：缓存**不能用来精确复算 601**，只能用来验证判定逻辑（第二节那条零例外的关系不受影响）。
要精确复算，需要乙把 `result-2026-11-19-final.json` 一并交出——那才是样本级基准。

## 七、两个公开数据集的实际核查结论（2026-11-20 实测）

老师提供过两条线索，逐条验证如下。

### 数据堂 2657 小时普通话自然对话（ModelScope `DatatangBeijing/2657Hours-...`）

| 核查项 | 实测结果 |
|---|---|
| 页面/协议 | 存在，标 Apache License 2.0，3,631 次下载 |
| **仓库大小** | **179.53 KB** —— 2,657 小时 16k wav 应在 200GB 量级，说明上面只有样例 |
| 文件列表 API | `Code: 10020101037 无权访问该数据集` |
| 官网 | `datatang.net/dataset/1055` 为商业售卖页，完整数据需采购 |
| **数据形态** | 官方描述：「以自然方式进行**面对面交流**」「录音环境：相对安静的环境，无回声」「设备：安卓/苹果手机」 |

**结论**：名字里虽有 `Telephony`，实际是**用手机录的面对面对话**，非电话信道；且完整数据不可免费获取。

### 更根本的一条：公开语料不能当评估集

即使上述数据集可下载且是电话信道，**仍然不能用作 30 通评估集**：

老师的 `AntiFraud-SFT` 来自 TeleAntiFraud 反诈项目。拿公开中文对话/反诈语料做评估集，
极可能撞上其训练分布，**等于自己考自己**。老师写「冻结之后只用来打分，永远不拿去训练」，
防的正是训练/评估泄漏。

**因此：30 通评估集只能自录，先交 3 通试打验格式。** 公开语料只能在第 3 步补训练数据时考虑，
且老师原文要求「和第 1 步同样的方法另外录」，需其明确同意。
