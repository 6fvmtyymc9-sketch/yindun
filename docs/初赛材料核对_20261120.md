## 四、RDS / DCS 那句怎么写（最容易踩的一处）

**不能写**：「已迁移至华为云 RDS / DCS」（现在不成立，实例已释放）
**也不能留**：「正在迁移至…」（永远停留在进行中，评委会问进度）

**建议这么写**：

> 方案支持华为云 RDS for MySQL 与 DCS for Redis；开发期已在同一 VPC 内完成开通、
> 数据迁移与回迁验证（迁移前后六表逐行一致、业务零改动，仅切 `RDS_HOST` / `REDIS_URL`
> 两个环境变量）。为控制按需计费成本，演示环境当前使用 ECS 同机 MySQL / Redis，
> 迁移脚本与连接参数保留在仓库中。

这段话的好处：**每一句都发生过**，而且顺带展示了"能算成本"这个工程判断力。
答辩若被追问"为什么不用云数据库"，答"按需实例不能停机只能删，8 天要 133 元，
而初赛不要求云上常驻实例"——这是加分回答，不是减分。
