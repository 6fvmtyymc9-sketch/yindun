# TeleAntiFraud audio.zip 目录标签与内容不符：量化证据

采集时间：2026-11-23 · 数据源 `audio.zip`（13,711 条 mp3，全 TTS，48 kHz 立体声）
方法：GPU 上 faster-whisper large-v3 转录后，按关键词命中率统计（与标签无关，纯内容侧）

## 一、目录名与内容整体相反

| 目录 | 目录名义 | 可用转录 | 含诈骗话术 | 含日常通话用语 |
|---|---|---|---|---|
| `POS-*` | 诈骗（正样本） | 1,389 | 283（**20.4%**） | 730（**52.6%**） |
| `NEG-*` | 正常（负样本） | 1,398 | 1,344（**96.1%**） | 34（**2.4%**） |

诈骗话术词表：退款/贷款/理财/中奖/手术/保证金/流水/验证码/转账/返利/兼职/征信/冻结/安全账户/额度/垫付/刷单/投资/翻倍/收益/客服/快递丢
日常通话词表：预约/取车/订餐/外卖/菜品/理发/保洁/维修/物业/营业时间/地址/几点/上门/报价/挂号/车位/配送

```
喂,你好,我是租车公司的客服,你之前预订了我们的一辆帕萨特,那取车时间有变动吗?...
```

`NEG-*`（目录写“正常”，内容其实是诈骗）：

```
你好,这边是中航科技的信息专员,你最近是不是在找投资理财的项目?...非常稳健的投资项目...
```

## 三、这不是孤例，同一个数据集的三处标签问题

1. **`sft.zip` 的 `is_fraud` 全为 `true`**（7,177 条 true / 0 条 false）——导师 11-22 已认定是“公开发布的数据打包有问题”
2. **`audio.zip` 的 POS/NEG 目录名与内容整体相反**——本文档
3. **`sft_fixed/` 的 `answers` 是场景名**（“咨询客服”这类），不是二分类标签

因此本实验的取用方式为**按内容侧取用**：
- 正常对话 ← `POS-*` 组（订餐/外卖/租车/理发/家政/维修等）→ 1,370 条可用
- 诈骗对话 ← `NEG-*` 组 → 1,393 条可用

## 四、已知残留污染（诚实记录）

`POS-*` 组里仍有约两成含诈骗话术，典型是「积分商城客服：您的积分今晚 12 点清零」这一类。
按关键词统计，1,370 条“正常”里有 **64 条（4.7%）** 实为诈骗话术，例如：

```
喂你好我是电商平台的客服专员你的购物积分到今天晚上12点就要清零了你还没有兑换呢...
喂你好我是积分商城的客服小向我们看了您账户里的会员积分怎么就从来没有兑换用过呀...
```

最终 5,000 条训练集里正常侧只用到其中 834 条，折算污染约 **39 条（0.8%）**。
这可能与第三轮“刷单返利/客服类判宽容”有关，但量级不足以单独解释（见报告第六节）。
