## 八、中途出问题怎么办

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| `doctor` 报 Node 版本不够 | 码道自带 Node 是 22.11 | 按包 C「二·补」装到家目录，`export PATH` 后同一终端继续 |
| `hcloud` 报 `current profile unresolved` / 401 | 用了 `auth_switch` 写的是 DevKit 凭据库，不是 KooCLI 的 `~/.hcloud` | 用 `hcloud configure set` 重建 profile（参数我这边有，别自己编） |
| 创建报安全组不存在 | 智能体新建了一个组 | 让它改用 `yindun-db`，别新建 |
| 创建报子网 CIDR 不够 / 可用区不支持 | 可用区选错 | 让它先查该规格在哪些 AZ 有货 |
| 智能体反复试错不收敛 | 参数缺太多 | 把第 2.3 节的表按「我看到 VPC 是 vpc-default」这种口吻提示它，别说"用这个 ID" |
