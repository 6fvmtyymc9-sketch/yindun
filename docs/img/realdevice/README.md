## 微信为什么是"提示"而不是"拦截"：分两档，不是没做

代码（`NotiGuard.judgeWechat`）对微信通知按判定级别做两件事，**不是所有可疑都拦**：

| 级别 | 老人端动作 | 通知栏 | 子女端 |
|---|---|---|---|
| warn / high（45~89 分） | 屏幕**底部**弹黑底浮条「「某人的」的消息可疑 / 请勿点击消息中的链接或转账」 | **保留**，正文仍可点开 | 推「妈妈微信收到可疑消息」 |
| block（≥90 分且走到 S4 要钱/要码） | 同上浮条 | **撤掉**（`clearIfBlock` → `cancelNotification`） | 推同级告警，卡片打「已拦截」红标 |

- `rd01`（「急事借 300」）落在 warn，所以通知还在——那张照片**只能叫可疑提示**。
- 真正的"拦截"画面（通知栏那条消失 + 子女端「已拦截」标）**已有**，但是在模拟器里：
  `docs/img/demo/06-wechat-intercepted.png`（「王叔…手机丢了换号了，急用钱先转我2000」）。
- **不用改功能就能补真机版**：找一条能判到 block 的微信消息（要钱要码、冒充子女索款），
  弹提示后下拉通知栏，那条微信通知不在了 —— 拍这个对照，比拍微信界面更有说服力。
- 只有 block 才撤通知，是 11-16 定下的取舍：warn 可能是误报，把家人正常消息删掉代价更大。

1. 撤的只是**通知栏那一条入口**。微信聊天窗口里的消息删不掉——安卓不允许任何 App 读写微信聊天记录，
