# 评估集（calls_eval）· 录制与冻结说明

> 对应老师《AntiFraud-SFT 下一步计划》**第 1 步**：「30 通真人电话录音，冻结之后只用来打分，永远不拿去训练。」
> 目录还没录音时是空的，`labels.json` 是空模板。**录满 30 通、提交一次、commit message 写「评估集冻结」之后，本目录只读。**

---

## 一、为什么必须先有这个

老师那份计划一共 6 步，第 2~5 步全部依赖它：

```
第1步 评估集 30 通  ←── 你现在卡在这里
   ↓
第2步 基线表（规则 / DeepSeek / SFT 音频 / SFT 文本 / 融合）
   ↓
第3步 训练数据（另录 60~100 条，不能用同一批）
   ↓
第4步 LoRA 微调
   ↓
第5步 回评估集打分
```

**没有第 1 步，后面一步都做不了。** 这也是为什么现在 SFT 那条线整体停着。

而且老师在这份计划里写了一句对我们有利的话：

> 「前三步做完就有一份能写进报告的完整实验，**即使微调最后没效果，第 2 步的基线本身就是成果**。」

也就是说，**哪怕微调救不回来，只要评估集 + 基线表做出来了，答辩就有东西讲**。

## 三、录制要求（每条都是老师原文，不是我们自己加的）

| # | 要求 | 为什么 |
|---|---|---|
| 1 | **两个人用手机互打，开通话录音** | 真人说，不要用 TTS |
| 2 | **照着场景即兴说，不要逐字念稿** | 念稿的语气和真实通话不一样，而语气恰恰是要测的东西 |
| 3 | 正常通话里**故意放几个"像诈骗"的词**：「您尽快处理一下」「需要核实一下身份」「这边帮您登记」 | 只有这样才测得出误报——现在正常通话被判诈骗就是栽在这类词上 |
| 4 | 每通 **20~90 秒**，导出 **mp3 或 wav** | m4a 服务端解不开 |
| 5 | 命名 `eval_正常_物业停水_01.mp3` / `eval_诈骗_公检法_01.mp3` | 一眼能看出是哪类 |
| 6 | 每条配一份人工转写 `.txt`（ASR 识别出来再人工校对） | 用来对比"文本模式"和"音频模式" |
| 7 | 记录**录音人**和**日期**，填进 `labels.json` | 第 3 步要保证训练集是另一批人、另一批说法 |

> ⚠️ 第 7 条最容易忽略：第 3 步明确要求「训练数据必须和评估集是不同的录音，同一个人用同一套说法也不行」。
> 所以现在就得记下来是谁录的，否则到时候分不清，就得重录。

## 四、文件怎么放

```
cloud/test/calls_eval/
├── README.md                       ← 本文件
├── labels.json                     ← 元信息（文件名/标签/场景/录音人/日期）
├── audio/                          ← 正式评估样本，只放自录真人通话
│   ├── eval_正常_物业停水_01.wav
│   ├── eval_正常_物业停水_01.txt    ← 人工校对后的转写
│   ├── eval_诈骗_公检法_16.wav
│   └── ...
└── smoke_public/                   ← 12 条 MagicData 同事通话，**不计入 30 通**
    └── eval_正常_同事通话_01.wav~12   （仅用于验证上传/转写链路通不通）
└── rejected/                       ← 不合格样本，不进 items、不参与打分
    └── eval_正常_物业停水_01.wav      （15.92 s，低于 20 s 下限，待重录替换）
```

> `smoke_public/` 是 2026-11-21 从 `audio/` 移出来的。它是公开语料、非老人场景、非陌生来电、
> 诈骗 0 通，按老师标准不能算第 1 步的样本，只留作链路冒烟。`eval-baseline.js` 正式模式
> 只读 `labels.json`，因此不会误算进去。

`labels.json` 每录完一条加一项：

```json
{
  "file": "audio/eval_正常_物业停水_01.wav",
  "label": "正常",
  "scenario": "物业停水",
  "speaker": "甲/乙",
  "date": "2026-11-21",
  "duration_sec": 28,
  "transcript": "audio/eval_正常_物业停水_01.txt"
}
```

`transcript` 在 ASR 出稿 + 人工校对之前留 `null`，**不要照脚本原文填**——
脚本是提示词，实际说的是即兴内容，拿脚本当转写等于自己给自己出题。

录满后把顶层 `frozen` 改成 `true`、填 `frozenAt`，提交一次，commit message 写 **「评估集冻结」**。

## 五、冻结之后不许做的事（老师原文第 143~145 行）

- ❌ 不要拿评估集里的录音去训练
- ❌ 不要照着评估集的错例补数据，再在同一份评估集上报分
- ❌ 不要用 TTS 或大模型生成的正常通话来训练（TeleAntiFraud 就是栽在 TTS 上）
