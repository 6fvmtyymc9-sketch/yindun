## 一、装机后必须做完的 7 项

App 向导只列了 5 项必需 + 3 项推荐，其中**第 6 项和第 7 项不在向导里，但漏了会翻车**。

| # | 项目 | 路径 | 判定标准 |
|---|---|---|---|
| 1 | 基础权限 | 向导第 1 项 | 短信、电话、通讯录、通知全部「已授权」 |
| 2 | 悬浮窗权限 | 向导第 2 项 | 「已开启」 |
| 3 | 通知使用权 | 向导第 4 项 | 「已开启」 |
| 4 | 使用情况访问权限 | 向导第 5 项 | 「已开启」（红屏靠它认银行 App） |
| 5 | 紧急联系人 | 向导第 3 项 | 「已保存」 |
| 6 | 电池优化 | 向导第 6 项 →「前往设置」→ 点「银盾」 | **选「不允许」** |
| 7 | 应用启动管理 | 手机管家 → 应用启动管理 → 银盾 | 关掉「自动管理」，三个开关全开 |

### 第 6 项的语义陷阱

这一页的字面意思是反的：

- 「允许」= 允许系统**为了省电而限制它** → 银盾在后台会被冻结
- 「不允许」= 不要限制它 → 后台能一直跑（代价是费电）

副标题「建议选择，可延长电池续航时间」说的是省电，不是"让它更好用"。
设对的标志：返回列表后，「银盾」那一行右侧显示「不允许」。

### 第 7 项为什么必须单列

EMUI 有自己的应用启动管理，优先级比 Android 原生的电池优化高。
不关「自动管理」的话，锁屏放一会儿服务就被冻结，电话打进来照样不弹卡。
这一项 App 检测不到（系统没有查询接口），所以向导里刻意没列，也最容易漏。

## 二、验证步骤

### 步骤 1：开机自启动

| 项 | 内容 |
|---|---|
| 操作 | 重启手机。**重启后不要点开银盾**，等 60 秒 |
| 预期 | 通知栏出现常驻通知「银盾守护中」（划不掉） |
| 结果 | ☐ 通过 ☐ 失败 |
| 备注 | |

这一条是真机上最有价值的验证——模拟器做不到。它证明的是「老人不需要惦记着打开 App」，
也就是答辩时最容易被追问的那一句。

不出现的话，说明第 7 项没设好，或需要到应用详情里再允许一次自启动。

### 步骤 2：语音通道（银盾之外的前提）

| 项 | 内容 |
|---|---|
| 操作 | 用另一部手机拨进来；再用这台拨 `10000` |
| 预期 | 双向都通 |
| 结果 | ☑ 通过 ☐ 失败 |
| 备注 | 开启 VoLTE 并重启后双向通话恢复正常 |

不通就和银盾无关，先解决 VoLTE / SIM 卡，不要动代码。

### 步骤 3：陌生来电弹卡

| 项 | 内容 |
|---|---|
| 操作 | 另一部手机拨进来，**号码绝对不要存进这台手机的通讯录** |
| 预期 | 响铃 3~5 秒内全屏卡片，副标题是「<号码> · 不在通讯录里」，两个按钮「认识」「不认识」 |
| 结果 | ☑ 通过 ☐ 失败 |
| 备注 | 2026-11-16 21:45 实测：打进来正常显示弹窗 |

注意两个干扰项：

- 号码存进通讯录后就不弹了，这是设计如此（熟人号码一律不碰）。
- 如果这通是"通话中又打进来"，会走呼叫等待分支，不弹卡，只在日志里记一行。

### 步骤 4：点「认识」不撤销防护

| 项 | 内容 |
|---|---|
| 操作 | 在步骤 3 的卡片上点「认识」 |
| 预期 | 卡片消失、防护仍在；子女端收到「老人选了认识，通话超过 5 分钟将再次确认」 |
| 结果 | ☐ 通过 ☐ 失败 |
| 备注 | |

「点认识 = 15 分钟免打扰」这条早就拆掉了。点认识只是告诉子女，不延后下一次确认。

### 步骤 5：红屏拦截

| 项 | 内容 |
|---|---|
| 操作 | **先接听**，保持通话中，再打开银行 App |
| 预期 | 全屏红屏覆盖，银行 App 内容完全看不到 |
| 结果 | ☐ 通过 ☐ 失败 |
| 备注 | |

只响铃不接听不算通话中，不会红屏——这是设计如此，不是 bug。
红屏是覆盖层，手机自带截屏能拍到（模拟器上要靠 `dumpsys window` 取证，真机不用）。

### 步骤 6：5 分钟复问

| 项 | 内容 |
|---|---|
| 操作 | 接通后一直保持通话，满 5 分钟（真机只能等，没法加速） |
| 预期 | 弹出「这通电话已经聊了 5 分钟」+「电话那头，是您认识的人吗？」，带红框警示「不管是否认识，请警惕手机交易金钱」，**持续振动，点按钮才停** |
| 结果 | ☑ 通过 ☐ 失败 |
| 备注 | 2026-11-16 实测：满 5 分钟正常弹出 |

### 步骤 7：诈骗短信

| 项 | 内容 |
|---|---|
| 操作 | 另一部手机发一条带「转账」「验证码」「安全账户」字样的短信 |
| 预期 | 短信到达后约 1.2 秒，**屏幕底部**弹出浮条判词；子女端同步收到推送 |
| 结果 | ☐ 通过 ☐ 失败 |
| 备注 | |

浮条刻意放在底部：系统自己会从顶部弹「收到短信」的横幅，两条都放顶部会互相压住。
浮条依赖悬浮窗权限，权限被关时会退化成 Toast。

## 三、故障对照

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 电话双向不通，但能上网 | 没开 VoLTE / 卡没开通语音业务 | 设置 → 无线和网络 → 移动网络 → VoLTE 通话；确认卡槽 1 |
| 来电完全没反应，也不弹卡 | 守护服务没起来 | 从最近任务划掉 App 重开一次；检查启动管理三开关 |
| 响铃但不弹卡 | 号码在通讯录里；或这通是呼叫等待 | 换一个没存过的号码再试 |
| 点「认识」后 5 分钟不再问 | 已经是修复后的行为？——不是，应该照样问 | 说明装了旧包，核对 APK 构建时间 |
| 开银行 App 不红屏 | 只响铃没接听；或没开使用情况访问权限 | 先接听；再查向导第 5 项 |
| 短信不弹浮条 | 悬浮窗权限被系统回收 | 重开悬浮窗权限 |
| 装完包之后就不弹卡了 | 覆盖安装会杀进程，服务要等下一次系统重绑通知监听才起来 | **装机后不要再重装**，重装后等 30 秒或重开一次 App |

## 五、已知限制（真机上也一样，不是故障）

- **不能自动挂断电话**：Android 没有给第三方应用挂断权限。防线的定位是"截住资金动作"，不是挂电话。
- **拿不到通话录音**：Android 9 起限制通话录音，语音走 TTS 兜底。录音复盘只用于演练场景。
- **银行识别靠包名 / 标题白名单**：真机上要用实测补表，表外的银行 App 认不出来。
- **无法验证自启动是否真的开启**：系统没有查询接口，只能靠重启后通知栏有没有「守护中」间接判断。
