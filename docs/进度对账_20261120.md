### 11-20 今晚新增：根因与数据修复（计划外，但决定第 4 步怎么做）

| 项 | 结果 |
|---|---|
| 根因 | `sft.zip` 33,953 条里 `"is_fraud": false` 出现 **0 次**；13,388 条 messages 末尾是 user，答案在 `answers` 字段不进 loss → 模型只学过「是」 |
| 推翻的旧解释 | ①「正样本占多数」（train 实为 5,724 : 4,987 = 53:47，本就平衡）②「48k vs 8k 信道不匹配」（TTS 有效带宽 f99 1,886~4,436 Hz，真人 8k 是 1,580~2,855 Hz，重合） |
| 数据已修 | `tools/fix_sft_data.py` → `外部数据集/sft_fixed/`：train **21,422 条**（true 5,724 / **false 4,987**）、test 5,354 条；顺带查出正样本原本被重复计数（`SUAU-fraud` 与 `SUAUAU` 音频完全相同） |
| ⚠️ 这份数据不能当最终训练集 | 老师第 3 步明写「不要用 TTS 合成的正常通话来凑数」，`sft_fixed` **全是 TTS**。它只用于**验证修法是否有效**，最终训练集仍需真录 |
| 待验 | 三个 GPU 实验（三问法 / base 模型 / 200 条小重训），素材与 runbook 已备：`交付包/_outbox/明天上GPU_runbook_20261121.md` |
