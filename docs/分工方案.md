## 二、和方案里建议分工的三处不同

### 1. 阶段 A 全部由我做（方案里建议给同学甲）

原因：**隧道要两边配合，同学甲进不去学校容器。**

这条链路有两侧：学校容器（发起方）和华为云 ECS（接收方）。容器是学校平台分配的，密钥只有我有，
同学甲拿不到 SSH 权限。所以 A2（ECS 建账号）我做了，A3~A5（容器侧）也只有我能做。

**已经完成并实测**（2026-11-18 20:42）：

| 检查项 | 结果 |
|---|---|
| 学校容器 → ECS 22 端口 | 通 |
| ECS 建 `tunnel` 账号 | 已建，`nologin`，只能端口转发 |
| 受限公钥 `permitlisten` | 锁死 `127.0.0.1:8099`，不能开其他端口 |
| 隧道建立 | `remote forward success for: listen 127.0.0.1:8099` |
| ECS `curl 127.0.0.1:8099/health` | **200，83ms** |
| ECS `POST /risk` 冒充公安话术 | **p=0.9992，144ms** |

还剩两步没做：A4（SFT 服务改只监听 `127.0.0.1`）、A6（ECS `.env` 加 `SFT_URL`）。
A4 会导致平台映射的 44855 端口失效，所以放在演示前确认过 44855 没人再用之后再做。

**一个查到的细节**：方案写容器内监听 8000，我们 `.env` 里配的是 44855，
一开始以为对不上。实测发现两者不矛盾——容器内确实是 8000，44855 是平台把容器的 8000 映射出来的对外端口。
外部访问 `10.8.110.32:8000` 不通，访问 `:44855` 通（200，114ms）。

### 2. 阶段 B 的判定链我留着自己做，只把 B1、B7 给同学甲

方案建议 B 段整体给同学甲。我拆开了：

| 分给同学甲 | 我自己做 |
|---|---|
| B1 新增 `FraudType.js`、`Advice.js`（纯新增文件） | B2 `CallAudio.js` 通话复盘 |
| B7 清理 `MAAS_`/`Pangu` 引用 | B3 `server.js` 的 `/api/report` |
| | B4 `Guard.js` 的 `explain` |
| | B5 `Drill.js` 演练 |
| | B6 App 端 `Pangu.java` |

原因是这几条约束不能出错，而且答辩时会被追问：

- 点「认识」不能关掉防护
- 红屏的退出语义是「挂断」不是「关闭」
- SFT 单票高分不告警，必须规则附和才抬到 S2

这些是产品逻辑的底线，改错了是事故。同学甲没有参与过判定链的设计讨论，让他接手这三条规则，
风险比我自己改要大。B1、B7 是纯新增和纯删除，边界清楚，给他没问题。

## 三、评估集的情况（需要您知道）

方案第 419 行的答辩话术写的是「30 通真人录音的冻结评估集」。**这一条现在兑现不了。**

试过的渠道：

| 渠道 | 结果 |
|---|---|
| TeleAntiFraud-28k（ModelScope） | 作者的仓库设了白名单，API、直链、git 三种方式都 403；HF 上是 gated，主站打不开 |
| 公开中文短信数据集 | 能下，但都是微博/论坛语料，不是通话 |
| 找人录 | 诈骗话术找人念是可行的，但凑不齐 30 通 |

现在手上能用的：

| 数据 | 规模 | 性质 |
|---|---|---|
| Fraud-R1 中文 | 1,070 条 | 真实诈骗**文本**（短信/邮件形态，不是通话） |
| MagicData 会议对话 | 87MB | **真人真录音**，正常对话 |
| MagicData 重口音对话 | 225MB | **真人真录音**，带口音 |

所以现在的计划是先出一版「文本基线」：Fraud-R1 当诈骗正样本，MagicData 当正常负样本。
它能回答「规则漏报多少、正常通话误报多少」，但**不能叫通话基线**，因为正样本不是电话对话。

答辩话术建议改成「在 1,070 条真实中文诈骗文本 + 两份真人对话语音上」，
等哪天真拿到通话数据再补一版覆盖。

## 四、还没确定的两件事

1. **代金券能不能买 RDS/DCS**。目前看到的是「测试类」，适用范围没写清。
   如果只能买 AI 类服务（OCR、SIS），RDS 和 DCS 就得自己出钱，按需计费演示期开机大概几十块。
2. **`.env` 里要不要现在就接 SFT**。接上之后线上每次通话复盘会等 SFT，
   容器不在线时降级等 8 秒（`SFT_WAIT_MS=8000`；⚠️ 老师 11-20 新增 `/judge` 后单次 3~60 秒，该值需 ≥60000）。现在线上 `sft.enabled` 还是 `false`。
