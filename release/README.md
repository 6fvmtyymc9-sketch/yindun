# 交付包（APK）

四个包共用同一把签名钥匙（`yindun.jks` / alias `yindun`），可以互相覆盖安装。
**下载后直接装，不需要先卸载旧版。**

| 文件 | 包名 | 装在哪 | 说明 |
|---|---|---|---|
| `Yindun.apk` | `com.yindun.guard` | 老人手机 | 银盾主体。48 MB，内含端侧模型 |
| `ChildDemo.apk` | `com.yindun.child` | 子女手机 | 银盾家人。收预警、看时间线 |
| `BankDemo.apk` | `com.icbc.mobile` | 老人手机 | 假银行壳，替代真实银行 App 做演示 |
| `WechatDemo.apk` | — | 老人手机 | 微信壳，替代真实微信做演示 |

## 装机后必须做的设置

**只装 APK 是不够的**，权限没配全，来电不会弹卡。完整清单见
[`docs/真机验证清单.md`](../docs/真机验证清单.md)，其中两项最容易漏：

1. **电池优化要选「不允许」**
   这一页的字面意思是反的——「允许」= 允许系统为省电限制它，银盾会被冻结。
   设对的标志：回到列表，「银盾」那行右侧显示「不允许」。

2. **手机管家 → 应用启动管理 → 银盾 → 关掉「自动管理」，三个开关全开**
   这一项不在 App 的引导清单里（系统没有查询接口），但不做的话锁屏后服务会被冻结。

## 两条使用提醒

- **装好之后不要再重装。** 覆盖安装会杀掉进程，守护服务要等下一次系统重绑通知监听才恢复，
  中间这段时间来电不会弹卡。
- **测试来电的号码不要存进老人手机的通讯录。** 通讯录里的号码按熟人处理，不弹卡，这是设计如此。

## 构建方式

仓库不含完整构建环境，需要本机有 Android SDK 才能从源码重编：

```bash
# 老人端
cd app && bash build2.sh      # 产物 app/Yindun.apk

# 子女端
cd app/childapp && bash build_child.sh   # 产物 app/childapp/ChildDemo.apk
```
