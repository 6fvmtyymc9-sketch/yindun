## 二、系统架构

```
┌──────────────────────── 老人手机（银盾 App） ────────────────────────┐
│                                                                      │
│  短信广播 ──┐                                                        │
│  通知监听 ──┤                                                        │
│  通话状态 ──┼──→  判定引擎 Judge（本地，读 rules.json）              │
│  前台应用 ──┘            │                                           │
│                          ├──→ 四级判定 → 浮条 / 红屏 / 震动 / TTS     │
│                          └──→ 上报 ──┐                              │
└──────────────────────────────────────┼──────────────────────────────┘
                                       │ HTTPS
                          ┌────────────▼────────────┐
                          │   云端服务（ECS）        │
                          │  Express + 可选RDS       │
                          │  同构 Judge.js 复核      │
                          │  SSE /api/stream 推送    │
                          └────────────┬────────────┘
                                       │ SSE 长连接
                          ┌────────────▼────────────┐
                          │   子女端网页             │
                          │  短信栏 / 通话栏自动切换  │
                          └─────────────────────────┘
```

设计上的两个关键选择：

**判定放在端上，不放在云上。** 断网时手机照样能判、能拦。云端只做复核、留档、转发。
实测断网状态下浮条照常弹出，子女端那条推送会显示"云端没回话，这条还没发出去"，恢复后重试成功。

**规则只有一份，两端同构。** `rules.json` 同时被 `Judge.java` 和 `Judge.js` 读取。
改规则不用改代码，也不用重新训练模型。

## 四、判定引擎

### 4.1 打分规则

```
总分 = Σ(命中的关键词权重) + Σ(命中的反例权重，为负) + 发送方加权 + 链接加分
```

- **关键词**：217 条，覆盖冒充公检法、钓鱼链接、客服退款、贷款刷单、投资理财、冒充亲友、中奖补贴
- **反例**：33 条，银行通知、快递取餐码、正常验证码话术等，命中会减分
- **发送方**：陌生号码 +15，服务号 +0，通讯录 +0
- **链接**：正文含 `http(s)://`、`www.` 或 `t.cn/xxx` 裸短链，+20 并保底 S2
- **验证码**：按发送方区别对待——服务号发的验证码是正常业务不加分；陌生人要验证码是 S4

### 4.2 灰区复审（可选）

本地分数 30–45 之间的短信，且发送方不是服务号时，会送华为云 MaaS 大模型复审一次。
规则很硬：**模型只能升级，不能降级**——模型说是诈骗就提高等级推子女端，
模型说不是就什么都不做，绝不撤掉已经报出去的警报。

模型选的是 **DeepSeek（`deepseek-v4.1-flash`）**，跑在**华为云 ModelArts Studio（MaaS）**上，不是盘古。
选它的三个理由：盘古是思考型模型，先吐思考链，JSON 解析容易跑偏；DeepSeek 非思考型，
2 秒内出结果、比 glm-5.2 便宜 4~4.5 倍；中文话术理解够用。赛题要求的是"调用大模型能力"，
用 MaaS 平台上的哪个模型都算，换模型不等于换平台。

## 六、开发过程：码道 CodeArts 智能体的实际使用

赛题把「华为云码道 CodeArts 代码智能体」列为必选项，并要求体现它在需求理解、代码生成、
项目构建、问题修复、部署上线各环节的使用价值。这一节只写**实际发生过的**，没做过的环节
不补写（见 6.4）。

### 6.1 需求理解：先把要求拆成可执行的清单，再交给智能体

2026-10-28，可视化演示页（`银盾反诈守护.html`）已经能跑通主流程，但文案和交互经不起
现场追问——评委要当着面点按钮走流程，一句话说错就会被问住。

当时的做法不是丢一句"帮我优化这个页面"，而是先把问题拆成 5 组**增量改动**，
写成《码道补丁清单 v1》（已随仓库提供：`docs/码道补丁清单_v1.md`），再整段交给码道执行。

清单开头给了三条硬约束，全是针对"模型容易改跑偏"的：

> 1. 不许重写整个文件，只做增量修改。
> 2. 不许改现有配色、字号、圆角、阴影、动画、手机框尺寸。
> 3. 不许引入任何外部 CDN、字体、图标库（答辩现场可能断网）。

### 6.2 代码生成：按清单改页面，而不是重画

码道按清单逐条改：5 处文案修正、左屏提示、子女端卡片措辞。
产出文件的修改时间（10-29 14:14）晚于清单（10-28 22:57）。

清单末尾还加了一段"交付要求"，要求逐条回答、不许合并：

> 1. "认识"和"不认识"两个按钮的宽度、高度、字号分别是多少？是否完全一致？
> 2. 红屏的显示条件是什么？把那段代码原样贴出来，确认里面没有引用"点了认识"这个状态。
> 5. **做不了清单（必填，没有就写"无"）**：哪条要求没做到、卡在哪、为什么。这一项不许留空。

第 5 条是刻意设计的：让模型自己交代没做到的部分，比事后人工逐条核对省事，
也避免了"看起来全改了、实际有一条没动"这种情况。

### 6.3 后续去向

`银盾反诈守护.html` 是现在两处界面的原型：

- 云端演示页 `cloud/public/index.html`（评委在浏览器里看的那个）
- 老人端网页 `app/assets/guard.html`

### 6.4 没有经过智能体的环节，如实说明

**项目构建**（Gradle 打包、签名）、**问题修复**（模拟器上 `syncAndDrawFrame` 那个 ANR）、

## 七、部署

### 6.1 App

```bash
cd app
./gradlew assembleDebug      # 或 bash build2.sh
adb install -r release/Yindun.apk
```

安装后必须手动授予四项权限，缺一项对应防线失效：

| 权限 | 作用 | 缺失后果 |
|---|---|---|
| 短信权限 | 收短信广播 | 短信防线完全失效 |
| 悬浮窗权限 | 弹浮条、盖红屏 | 所有视觉提醒都出不来，只剩子女端收到 |
| 通知使用权 | 读微信通知 | 微信防线失效 |
| 使用情况访问 | 识别前台应用 | 银行拦截失效 |

另外建议加入电池优化白名单并锁定后台，否则国产 ROM 会杀进程。

### 6.2 子女端 App

```bash
cd app/childapp
bash build_child.sh          # 产物 ChildDemo.apk
adb install -r release/ChildDemo.apk
```

构建脚本会从 `local.properties` 的 `yd.server` 注入服务器地址，生成 `ServerGen.java`
（该文件已列入 `.gitignore`，真实地址不进仓库）。没配 `yd.server` 也能编译，
装好后长按顶部标题栏手动填地址即可。

运行时权限只有一个：**通知**（Android 13+）。不给的话卡片照常更新，但没有响铃和横幅。

### 6.3 双模拟器（演示视频用）

```bash
# 一台电脑跑两台，包名不同所以互不覆盖
D:\Android\启动双模拟器.bat
```

脚本按 5554（老人）与 5556（子女）两个端口启动，等两台开机完成后再统一关掉自动息屏。
机器建议 16 GB 内存；跑之前退出 Android Studio，它常驻约 1.2 GB。

时区如果不是北京，会显示差 8 小时：

```bash
for P in 5554 5556; do
  adb -s emulator-$P shell "cmd alarm set-timezone Asia/Shanghai"
  adb -s emulator-$P shell "settings put system time_12_24 24"
done
```

### 6.4 云端

```bash
cd cloud
npm install
cp .env.example .env        # 填 RDS_HOST / RDS_USER / RDS_PASS / RDS_DB / REDIS_URL / PORT
mysql -h "$RDS_HOST" -u "$RDS_USER" -p < sql/schema.sql                            # 建表
mysql -h "$RDS_HOST" -u "$RDS_USER" -p yindun < sql/migrate_20261111_event.sql       # 必须执行：Db.js 依赖它加的 call_id / kind 两列
node src/server.js
```

> 键名是 `RDS_*`，不是 `DB_*`——代码读的是 `process.env.RDS_HOST` 等（`cloud/src/server.js` 的 `initPool`）。
> 写成 `DB_HOST` 服务会认为"未配置 RDS_HOST"，直接降级成内存存储，数据一条都不落库，而且不报错。

可选依赖：

- **MySQL（RDS）**：可选。配了 `RDS_HOST` 才连，连不上自动降级为进程内存，
  服务照常启动（`Db.js` 里 `online=false` 就不走 SQL，演示不中断）。
  代价是进程重启后历史告警丢失，所以正式部署要配实例
- **Redis**：可选，缺失时降级为单机内存
- **华为云 MaaS 大模型（DeepSeek）**：可选，缺失时跳过灰区复审，本地规则照常工作

健康检查：`GET /api/health` 会自报规则版本与各依赖连接状态。

**AI 接口有额度。** `/api/report`（截图复审）和 `/api/drill/turn`（演练对练）背后是真实的大模型调用，
按 token 计费。服务端在它们前面挡了一道按 IP、按北京时间每天清零的限额：默认识别 60 次、演练 300 次，
可用 `RATE_REPORT_PER_DAY` / `RATE_DRILL_TURN_PER_DAY` 调整，填 0 关闭。

超额时返回 `200 + {ok:false, code:"RATE_LIMITED", msg}`，不是 429——因为 App 的网络层
（`DrillNet.request`）遇到非 2xx 会把响应体丢掉、返回 null，界面上会显示"连不上云端，检查一下 WiFi"，
而老人明明连着网，那是假信息。给 200 才能把"今天的识别次数用完了"如实弹出来，客户端一个字都不用改。
计数走 Redis，Redis 挂了自动退进程内存；限流器本身出异常时一律放行，不阻断演示。

### 6.5 签名

仓库不含密钥。`build.gradle` 从 `local.properties` 读四项：`yd.storeFile`、`yd.storePassword`、
`yd.keyAlias`、`yd.keyPassword`，缺任何一项会直接抛 `GradleException`（不会静默用 debug 签名）。
`build2.sh` / `build_child.sh` / 两个壳的构建脚本同样从 `local.properties` 取密码，源码里没有明文。
换成自己的密钥后重新构建即可，注意包名不变才能覆盖安装。

## 八、已知缺陷

按严重程度排序，全部是真实存在的，不是"待优化项"这种模糊说法。

1. **不能自动挂断电话。** Android 没有给第三方 App 挂断他人通话的权限。系统 API 只允许挂断自己发起的通话。
   所以防线设计成"截住资金动作"——盖屏、拦银行、通知子女，而不是挂断。
2. **微信聊天界面内是盲区。** 通知监听读的是通知，老人正开着聊天窗口时微信不会重复发通知。
   补这个需要无障碍读全屏文字，误报高、耗电、隐私也讲不清，所以没做。
3. **银行识别靠包名白名单。** 没有银行接口，只能靠 `QUERY_ALL_PACKAGES` 读前台包名与标题。
   换一家没收录的银行就不生效，需要扩表。
4. **语音默认是 TTS 合成。** assets 里没有预录音频，靠系统 TTS 念固定话术，音色取决于机型。
   子女在子女端上传过提醒语音后，红屏会**优先播亲人的原声**（`FamilyVoice.java`），TTS 退为兜底。
5. **自启动引导做了，但没法判断开没开。** 设置面板「自启动管理」会按厂商试 9 个已知的自启动页
   组件（华为/荣耀、小米、OPPO/一加、vivo/iQOO、三星、魅族），全打不开时退回应用详情页并给出本机路径。
   但系统不提供"自启动是否已开启"的查询接口，所以这一项**不进设置向导的完成度**——
   放进去的结果是「已完成 x/8」永远差一个，老人会以为是自己没弄好。
6. **模拟器需要软件渲染。** 该模拟器 GPU 不可用（`eglChooseConfig failed`），WebView 硬件渲染会让主线程
   卡在 `syncAndDrawFrame` 导致 ANR，已强制 `LAYER_TYPE_SOFTWARE`。真机不需要这个开关，页面很轻，
   走软件渲染也不慢。
7. **子女端历史记录的时间筛选。** 之前的 `created_at` 过滤会差 8 小时（服务器 UTC / 浏览器 +8），
   现在改成"默认取最近 20 条"。
   **2026-11-11 实测：显示本身已经是对的** —— mysql2 把 DATETIME 转成 JS Date，接口序列化成
   带 `Z` 的 ISO（例如 `2026-11-11T07:15:14.000Z` 对应北京时间 15:15），前端按本地时区渲染。
   残留的只是"按时间窗筛选"这件事本身不可靠，所以没做筛选。
8. **子女端 App 的实时性依赖长连接。** 靠前台服务保活，通知栏会常驻一条「银盾正在守护」。
   如果系统仍然把它杀掉（国产 ROM 严格省电策略），会退回 3 秒一次的重连，最坏延迟 3 秒。
   真正的生产方案应该换成厂商推送通道（华为 Push / 小米 Push），这次没做。
9. ~~子女端只有一位老人~~ → **2026-11-11 已做**。子女端现在是老人名单（`Conf.elders()`），
   顶栏点称呼就能换人，可以改名、解除绑定、再加一位。云端 **一行没改** ——
   一条配对 token 本来就只对应一位老人（`/api/pair/claim` 每次发新 token），
   所以只要客户端把多个 token 管好就够了。实测两位老人各自 1 条 / 3 条预警，
   切换后列表跟着换，且**未选中那位老人的推送不会串进来**（详见下方第 10 条踩到的坑）。
10. **重连会留下第二条长连接（2026-11-11 已修）。** `Hub.restart()` 原来只把 `started` 置 false
   再起一条新线程，但老线程正阻塞在 `readLine()` 上、没人关它 —— 于是同时存在两条 SSE，
   一条订阅上一位老人、一条订阅这一位。实测现象：切到"妈妈"之后，另一位老人的预警
   照样跳进妈妈的列表，还弹了系统通知。修法是加连接代次 `generation` + 主动 `disconnect()`
   掐断老连接，老线程看到代次变了就退出、并且不再把老连接上的数据写进列表。
   **这个坑在"单老人"时代就有**（改服务器地址、点重连都会触发），只是没有第二位老人时看不出来。

## 九、演示中哪些是模拟的

必须说清楚，避免答辩时被追问。

| 环节 | 真实部分 | 模拟部分 |
|---|---|---|
| 短信 | 真短信进系统短信库、真通知、真判定、真浮条 | 由 `adb emu sms send` 注入，不是另一部手机发的 |
| 来电 | 真来电界面、真通话状态、真判定 | 由模拟器注入 |
| 微信 | 真系统通知、真通知监听、真判定 | 微信本身是壳（装在模拟器里，登录不了真微信） |
| 银行 | 真前台应用、真包名识别、真红屏 | 银行 App 是壳（没有工行接口与账号） |
| 云端 | 真 Node 服务、真 MySQL、真 SSE | 无 |

换到真机只需要：把 `adb emu sms send` 换成另一部手机发短信，把模拟器来电换成真电话。
代码一行不用改。微信和银行壳要换成真 App，需要扩银行的包名表，微信不需要改（通知格式一致）。
