> **2026-11-24 补记（真值核对）**：本文档初版（11-23）只用关键词命中率推断。现补上 `sft.zip` 自带的逐条标签作真值，结论从「推断」升级为「核对」。

## 一、官方真值：目录名 100% 与判定标签相反

`sft.zip` 共 33,953 行（train 27,146 + test 6,807），`answers` 是字符串标签，**同一条音频对应 2~3 行**（判定 + 诈骗类型 + 场景）：

```
('NEG-imitate-11', 'tts_test1914') -> ['fraud', '银行诈骗', '咨询客服']
('POS-imitate-4',  'tts_test520')  -> ['normal', '日常购物']
```

按「判定类标签」归并（优先取 `fraud`/`normal`，其次是 `XX诈骗`/`身份盗窃`，忽略 `咨询客服`/`订餐服务` 这类场景标签），得到 13,388 条音频的唯一定论：

| 目录 | 条数 | 官方判定标签 | 一致率 |
|---|---|---|---|
| `NEG-*`（名义「正常」） | 7,177 | **fraud 7,177** | **100.0%** |
| `POS-*`（名义「诈骗」） | 6,211 | **normal 6,211** | **100.0%** |

**不是「大部分相反」，是严格 100% 相反，零例外。** 这说明问题出在打包时的目录命名（POS/NEG 两个词被互换），数据集本身的标注是干净、有区分度的。

诈骗侧还带细类，可直接用于分层：客服诈骗 2,521 / 银行诈骗 2,040 / 投资诈骗 995 / 钓鱼诈骗 551 / 彩票诈骗 517 / 绑架诈骗 416 / 身份盗窃 137。

## 二、我们第三轮训练数据的标签，与官方真值 100% 一致

按「组名 + 文件名」把转录结果对回 `sft.zip` 真值（脚本见下），核对第三轮实际用的两份数据：

| 训练文件 | 我们的标注 | 对上真值 | 一致 | 一致率 |
|---|---|---|---|---|
| `taf_normal.jsonl`（1,370 条，取自 `POS-*`） | normal | 1,365 | 1,365 | **100.0%** |
| `taf_fraud.jsonl`（1,393 条，取自 `NEG-*`） | fraud | 1,329 | 1,329 | **100.0%** |

（差额是长度/重复过滤掉的样本，不是标签错误。）

**结论：第三轮训练数据没有标错一条。** 第三轮的结果（误报清零、召回下滑）不是标签噪声造成的，可以放心用于结论。

|---|---|---|---|---|
| `POS-*` | 诈骗 | 1,389 | 283（20.4%） | 730（**52.6%**） |
| `NEG-*` | 正常 | 1,398 | 1,344（**96.1%**） | 34（2.4%） |

## 四、残留问题：生成内容与标注意图的偏离（不是标错）

`POS-*`（官方标 normal）里有 64 条（4.7%）文本读起来像营销诱导，典型是「积分商城客服：您的积分今晚 12 点清零」。例如：

```
喂你好我是电商平台的客服专员你的购物积分到今天晚上12点就要清零了你还没有兑换呢...
喂你好我是积分商城的客服小向我们看了您账户里的会员积分怎么就从来没有兑换用过呀...
```

这类文本官方仍标 `normal`，因为它们不索要转账、验证码、不引导下载——是**营销骚扰**而非诈骗。折算进 5,000 条训练集约 39 条（0.8%）。

所以准确表述是：**标注没错，是个别生成内容偏离了「日常通话」的意图**。它可能是第三轮「客服类判宽容」的一个促成因素，但量级不足以单独解释（见报告 §7.7）。

## 五、取用方式与复现

- 正常对话 ← `POS-*` 组（订餐/外卖/租车/理发/家政/维修），官方标 normal
- 诈骗对话 ← `NEG-*` 组（冒充客服/银行/投资/钓鱼），官方标 fraud
- 转换脚本 `tools/taf_to_judge.py` 顶部注释写明依据

核对脚本（本机运行，两个 zip 都在 `D:/下载/`）：

```python
import zipfile, json, os, collections
z = zipfile.ZipFile('D:/下载/sft.zip')
per = collections.defaultdict(set)
for n in ['sft/train.jsonl', 'sft/test.jsonl']:
    for line in z.open(n):
        d = json.loads(line); a, au = d.get('answers'), d.get('audios') or []
        if not au or not isinstance(a, str): continue
        p = au[0].split('/')
        per[(p[-3], os.path.basename(p[-1]).rsplit('.', 1)[0])].add(a)

def verdict(ls):
    if 'fraud' in ls: return 'fraud'
    if 'normal' in ls: return 'normal'
    return 'fraud' if any(x.endswith('诈骗') or x == '身份盗窃' for x in ls) else 'unknown'
```

结果存档：`label_check_r3.json`（本目录）。
