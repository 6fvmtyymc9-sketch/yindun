## 五、回迁过程（可复现，2026-11-20 12:50–13:16）

全部在 ECS 上通过 SSH 执行，未新增任何云资源、未产生额外费用。

| 步 | 动作 | 结果 |
|---|---|---|
| 1 | 备份 | `backup-mysql-1120.tar.gz`（5.5M）、`backup-redis-1120.rdb`、`env-backup-1120.txt` |
| 2 | 启本机服务 | MySQL 8.0.46 + Redis 起来，只监听 `127.0.0.1` |
| 3 | 导出 | 从 RDS `mysqldump --single-transaction --no-tablespaces --set-gtid-purged=OFF` → 1.4M |
| 4 | 导入 | 建库 `utf8mb4_0900_ai_ci` 后导入 |
| 5 | **七表对数** | `yd_alert 1589 / yd_drill 10 / yd_event 0 / yd_known 0 / yd_report 1225 / yd_rules 0 / yd_user 2` —— 与本机逐表一致 |
| 6 | 切 `.env` | `RDS_HOST=127.0.0.1`、`REDIS_URL=redis://127.0.0.1:6379/0` |
| 7 | 重启验证 | `health` 全绿，`statsAll` 1589 / 1225 对上 |
| 8 | **写库实测** | POST 一条 → `yd_report` 1225→1226 → 删除 → 回 1225 |
| 9 | 终检 | `ss` 无连接指向 `192.168.0.90` / `.138`；crontab 无残留；`NRestarts=0`；近 5 分钟报错 0 行 |

**三点值得记住的坑**：

1. **`RDS_PASS` 含 `#`**：shell 里 `-p$PASS` 会在 `#` 处被当成注释截断，报 `Access denied`，
   看着像密码错，其实是被截了。凡含特殊字符一律用 `MYSQL_PWD="$PASS"`。
2. **`yd_report` 的文本字段叫 `excerpt`**，不是 `text`。
3. 本机账号用独立密码（与云上脱钩），避免以后再被特殊字符拖累。

**回滚路径**：改回 `.env` 两个值 + `systemctl restart yindun`，30 秒。云上实例已释放，
如需重开，参数照 `RDS_DCS_开通记录_20261119.md` 抄即可（三个坑都已写明）。
