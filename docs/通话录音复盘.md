# 通话录音复盘（挂断后）

陌生来电挂断后，银盾去找手机系统电话自带的通话录音，传到云端转成文字，
用大模型判断是不是诈骗、走到了第几步。判成有风险：

- 老人手机弹提醒「刚才那通电话可能是骗子 · 先别转钱」
- 子女端收到卡片，带诈骗类型、阶段和对话里的原话
- **之后 30 分钟内打开手机银行，直接红屏**（骗子常让老人挂了电话再去转账）

目标机型：**荣耀老机型**（EMUI / Magic UI，国行版电话自带「自动通话录音」）。

---

## 一、它和原来的设计是什么关系

| | 实时拦截（原有） | 通话录音复盘（新增） |
|---|---|---|
| 什么时候 | 通话中 | 挂断后 |
| 看什么 | 动作：开银行、收验证码、通话时长 | 对话内容（系统录音转写） |
| 依赖网络 | 不依赖，本地规则 | 依赖云端 |
| 能做什么 | 盖屏、拨给子女 | 提醒老人、推子女、布下 30 分钟银行拦截 |

实时这一层照旧**不读通话内容**、断网能拦；复盘是在老人授权后补上的第二层。

**我们自己不录音。** 安卓 9 起第三方 App 拿不到通话音频，读的是系统电话生成的录音文件。

---

## 二、链路

```
挂断（CallWatcher → Guard）
  └→ CallRecord：只处理陌生号码、老人已开启、有文件权限
       └→ 每 3 秒扫一次录音目录，找"这通电话期间写入"的最新音频，等它不再变大
            └→ POST /api/callaudio（音频 base64）
                 ├→ Asr：转文字（华为云 SIS / OpenAI 兼容接口 / 演示转写稿）
                 ├→ Judge.js：规则打分，给可解释的命中词
                 ├→ Pangu.judgeCall：大模型定阶段、摘原话证据
                 └→ warn 以上：落库 + SSE 推子女端
       └→ 收到结论：弹提醒；high/block 开 30 分钟银行拦截窗口
```

两路判定怎么合（`cloud/src/CallAudio.js`）：

- 有大模型：**模型定阶段**。转写稿长、口语化、分不清说话人，逐词打分会被
  「我不会告诉你验证码」这种话误伤，语义判断更准。
- 保险：规则看到「要钱」(S4) 但模型说不是诈骗 → 不放过，降为 S2 提醒子女核实。
- 没大模型：用规则结果兜底，卡片上标「仅规则判定」。
- 模型给的"原话证据"会逐条核对是否真在转写稿里出现，编的直接丢掉。

阶段 → 等级：S4 block / S3 high / S2 warn / S1 watch / S0 none。warn 以上才推子女、才打扰老人。

## 四、权限（按安卓版本）

| 系统 | 需要 | 说明 |
|---|---|---|
| 安卓 9 及以下 | 存储权限 `READ_EXTERNAL_STORAGE` | 荣耀 9/10/20 等 |
| 安卓 10 | 存储权限 + 清单里 `requestLegacyExternalStorage="true"` | 已加 |
| 安卓 11+ | 「允许访问所有文件」 | 首页点开关会带过去 |

另外老人手机上要做两件事：
1. 系统电话 → 设置 → 通话录音 → 打开**自动通话录音**
2. EMUI 杀后台很狠：「应用启动管理」里把银盾改成手动管理、三个开关全开；最近任务里锁住银盾

## 五、真机适配（拿到荣耀机后第一件事）

录音路径以实测为准。打开自动录音 → 打一通电话 → 挂断 → 电脑上运行：

```bash
adb shell "find /sdcard -mmin -5 -type f \( -name '*.mp3' -o -name '*.m4a' -o -name '*.amr' -o -name '*.aac' -o -name '*.wav' \) 2>/dev/null"
```

找到的目录如果不在 `CallRecord.java` 的 `DIRS` 里，加一行即可。目前的猜测顺序：

```
Sounds/CallRecord        华为 / 荣耀 EMUI 9+、Magic UI（首选）
record                   更老的 EMUI
Recordings/Call ……       其他机型
```

## 六、云端配置

```ini
# 语音识别：二选一。都不配时，只能用录音旁边的同名 .txt 演示转写稿
SIS_PROJECT_ID=...           # 华为云 SIS 一句话识别（≤60 秒）
SIS_TOKEN=... 或 HW_IAM_USER / HW_IAM_PASS / HW_IAM_DOMAIN
# 或
ASR_URL=https://.../v1/audio/transcriptions
ASR_KEY=...

MAAS_KEY=...                 # 大模型（原来就有）
YD_TOKEN=...                 # 建议设：新接口要校验身份
```

自检：`curl http://<服务器>:8080/api/callaudio/ping` → 返回当前转写方式和模型。

## 七、模拟器演示

模拟器没有系统通话录音，也没有通话声音。所以"录音文件"由 adb 放进去，后面的链路全部真跑。

```bash
# 1. 生成演示录音（只需一次，已生成好放在 demo/calls/）
bash demo/calls/make_calls.sh

# 2. 打包安装
bash app/build_mac.sh
adb install -r app/build_mac/Yindun-debug.apk
```

3. 银盾首页点「通话录音复盘」→ 同意 → 打开「允许访问所有文件」
4. 把后端指向本机云端（模拟器里本机是 `10.0.2.2`）。老人端首页没有这个设置入口，
   用 adb 写（只对 `build_mac.sh` 打出来的可调试包有效；会覆盖第 3 步的开关，所以一起写上）：

```bash
adb shell am force-stop com.yindun.guard
adb shell "run-as com.yindun.guard sh -c 'mkdir -p shared_prefs && cat > shared_prefs/yindun.xml'" <<'XML'
<?xml version='1.0' encoding='utf-8' standalone='yes' ?>
<map>
    <string name="backend">http://10.0.2.2:8080</string>
    <boolean name="rec_on" value="true" />
    <boolean name="asked_model" value="true" />
</map>
XML
adb shell am start -n com.yindun.guard/.MainActivity
```

5. 三个场景：

```bash
bash demo/calls/call_test.sh 13900001111 demo/calls/13900001111_20261109103015.mp3   # 冒充公检法
bash demo/calls/call_test.sh 13700002222 demo/calls/13700002222_20261109141020.mp3   # 冒充亲友借钱
bash demo/calls/call_test.sh 13600003333 demo/calls/13600003333_20261109160530.mp3   # 物业来电（对照）
```

6. 第一个场景之后，打开工行壳（`release/BankDemo.apk`）→ 直接红屏

**预期结果**（2026-11-09 在 API 36 模拟器上实测，转写用演示稿，大模型用本地模拟接口）：

| 录音 | 阶段 | 老人手机 | 子女端 |
|---|---|---|---|
| 冒充公检法 | S4 要钱 / block | 弹「刚才那通电话可能是骗子」 | 卡片：冒充公检法 + 原话 |
| 冒充亲友借钱 | S3 隔离 / high | 同上 | 卡片：冒充亲友 + 「别告诉」 |
| 物业来电 | S0 / none | 不打扰 | 无 |
| 公检法之后打开工行 | — | 红屏「先别转钱」+ 振动 + 语音 | 卡片：挂断可疑电话后打开了手机银行 |

**注意**：`call_test.sh` 推完录音后会 `touch` 一下文件。`adb push` 会保留电脑上的旧修改时间，
而银盾只认"这通电话期间写入"的录音。

## 八、限制（答辩前看）

- **挂断后才有结论**，通话中听不到内容。实时拦截仍靠原来的动作信号。
- **只支持自带自动录音的机型**，录音路径要按机型实测。新款华为（纯血鸿蒙）装不了 APK。
- 单声道录音分不清谁在说话，靠大模型从语义区分。
- 华为云 SIS 一句话识别只收 ≤60 秒音频。真实诈骗电话往往更长，正式用要换成「录音文件识别」（需要先传 OBS），或在手机端切段。
- **SIS / OpenAI 转写接口和真实大模型都没有用真账号测过**，开发时只用了演示转写稿和本地模拟的大模型。第一次接入请先 `/api/callaudio/ping`，再拿一段录音实测。
- 子女端网页的标语写着「不听您说什么」「不含通话内容」，开了这个功能后要改口径。

## 九、答辩口径

- **两层**：实时拦截不读内容、断网能用；事后复盘在老人授权后分析录音。
- **隐私三条**：首次使用老人点同意；只分析陌生号码；音频不落盘、全文不入库，只留几句证据。
- **为什么挂断后还有用**：骗子常让老人挂了电话再操作转账。复盘结论出来后 30 分钟内打开银行就红屏，正好卡在钱出门之前。
