**时间**：2026-11-19 17:30
**起因**：甲用码道智能体开 RDS 时报「ECS 列表是空的」，判断是自己账号不对，停手求正确账号。

---

## 一、结论先行

**甲停手是对的，但「账号不对」这个结论只对了一半，而且真正的解法不是「找队长要账号」。**

我用项目 `.env` 里的 AK/SK 直接调华为云 API 查了一遍，结果：

| 查什么 | 结果 |
|---|---|
| 区域 | `cn-north-4`（华北-北京四） |
| ECS | **1 台：`ecs-b993`**，私网 `192.168.0.211` / 公网 `123.249.25.139`，状态 ACTIVE |
| VPC | **1 个：`vpc-default`**，`8f452f90-f5bd-4b51-ad48-4eb1d101552f`，网段 `192.168.0.0/16` |
| 子网 | `subnet-default`，`9bb53754-…`，`192.168.0.0/24`，挂在上面的 VPC |
| RDS 实例 | **0 个**（甲说得对，还没建成，没花钱） |
| DCS Redis | **0 个** |

**也就是说：账号里的资源一个不少，而且我们手里的 AK/SK 有完整的 RDS/DCS 权限。**

---

## 二、甲到底撞上了什么

### 2.1 两个账号各有一个叫 `vpc-default` 的默认 VPC

- 我们的账号（`hid_c7n0rhm2aeqwlq`）：`vpc-default` = **`8f452f90-…`**
- 甲登的账号（`hw011744650578942`）：他新建的 `vpc-default` = **`b1b68207-…`**

**同名不同 ID，这是最坑的地方。** 如果只看名字，会以为两边是同一个网络；
实际上它们在不同账号、不同 VPC 里，互相看不见也连不通。

这也是为什么他「查不到 `8f452f90`」——那个 VPC 根本不在他登的账号里。

### 2.2 他看到的 ECS 列表是空的，是真实情况

`ecs-b993` 在他的账号里确实不存在。这不是浏览器缓存、不是区域选错，
是**两个账号**。

### 2.3 但这里有个反直觉的地方

`hw011744650578942` 这个格式（`hw` + 15 位数字）不像华为云的「账号名」，
我们的账号名是 `hid_c7n0rhm2aeqwlq`。所以也有一种可能是：
它是同一个账号的另一种标识（账号 ID），而甲登进去的是**另一个华为账号**。

**不管是哪种，处理方式一样**：以「能不能看到 `8f452f90` 这个 VPC」为唯一判据。

## 三、真正的解法：不需要甲那个账号

### 3.1 我们能直接用 API 开 RDS

验证结果（全部只读 GET）：

```
GET /v3/{project}/datastores/MySQL        → 200，8.0.45 / 5.7.44 / 8.4.7
GET /v3/{project}/flavors/MySQL?version_name=8.0 → 200，274 个规格
GET /v1/{project}/subnets                 → 200，subnet-default 在 8f452f90 下
GET /v3/{project}/instances（RDS）         → 200，0 个
GET /v2/{project}/instances（DCS）         → 200，0 个
```

**返回 200 不是 403，说明这个 AK 有对应的服务权限。**

最小可用规格（单机版 MySQL 8.0）：

| 规格 | 核/内存 | spec_code | 可用区 |
|---|---|---|---|
| **2 核 4G** | 最小 | `rds.mysql.x1.large.2`（x86） | `cn-north-4a / 4g / 4b` |
| 2 核 4G | 最小 | `rds.mysql.large.arm2.single`（ARM） | 同上 |

单机版一共 55 个规格可选，`single` 模式目前最小就是 2核4G。

### 3.2 这样做的好处

1. **VPC 天然正确** —— 建的时候直接指定 `8f452f90` + `subnet-default`，和 ECS 同一个网段，内网直连
2. **不需要控制台账号密码** —— 绕开 IAM 登录保护那个坑（我们试过密码换 token，401，
   说明这个 IAM 用户开了登录保护，控制台本来也进不去）
3. **可复现** —— 创建脚本会成为部署材料的一部分，答辩时能讲「基础设施即代码」

### 3.3 代价

**要花钱。** 按需计费，用完就能释放：

- RDS MySQL 2核4G 单机版 + 40GB 存储：按需大约 ¥1~2/小时
- DCS Redis 1GB 单机版：按需大约 ¥0.5~1/小时

演示跑两天（约 48 小时），**粗估百元以内**。具体金额以控制台结算为准，
我给不了精确到分的数——报价随区域和活动变化。
