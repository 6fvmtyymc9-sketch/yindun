# 交接 · 同学乙（评估集与文档）

> 你负责两件事：**把评估数据整理好、跑分脚本搭起来**；最后**把文档和截图收口**。
> 不需要服务器、不需要 GPU、不需要云账号，用你自己的电脑就能做。

---

## 一、为什么做这件事

银盾的核心是"判断一通电话/一条短信是不是诈骗"。要证明它判断得准，必须有一张表：

> 在 N 条已知答案的数据上，我们漏了多少、误报了多少。

现在这张表**不存在**。答辩时评委一问"准确率多少"，答不上来就完了。你的活就是把这张表变成一条命令能跑出来的东西。

---

## 二、你不需要做的事

- ❌ 不需要服务器、不需要云账号、不需要显卡
- ❌ 不需要改产品代码（`cloud/src/`、`app/src/` 一行都别动）
- ❌ 不需要训练模型（那是老师的事）

### 3.3 统一格式

建目录 `demo/eval-calls/`，每条样本一个记录，汇总在 `labels.json`：

```json
[
  {
    "id": "fraudr1-001",
    "source": "fraudr1",
    "kind": "text",
    "text": "（原文，或转写稿）",
    "audio": null,
    "label": 1,
    "type": "冒充公检法",
    "note": ""
  },
  {
    "id": "magic-001",
    "source": "magicdata",
    "kind": "audio",
    "text": "",
    "audio": "audio/magic-001.wav",
    "label": 0,
    "type": "",
    "note": "重口音正常对话"
  }
]
```

`label`：`1` = 诈骗，`0` = 正常。`kind`：`text` 纯文本，`audio` 有录音。

**注意**：Fraud-R1 是短信/邮件形态，不是电话对话。所以这版只能叫「**文本基线**」，报告里必须写明这个局限，不要写成"通话准确率"。

## 四、第二部分：跑分脚本

### 目标

一条命令，输出一张表：**每种方法在一批已知答案的数据上，漏报多少、误报多少。**

```
node demo/eval-calls/run.js
```

### 要对比的三路

| 路 | 是什么 | 怎么调 |
|---|---|---|
| 规则 | 我们的关键词规则引擎 | 调已经部署好的线上服务 `/api/report` |
| 端侧 TinyBERT | 手机本地的小模型 | 有现成实现，先接进来或先留空 |
| DeepSeek | 现在线上在用的通用大模型（对照组） | 同样走线上服务 |

**第四路 SFT 现在跑不了**：学校 GPU 在内网，隧道还没通。先做上面三路，等通了再补。

线上服务地址：`http://123.249.25.139:8080`，健康检查 `GET /api/health`，上报分析 `POST /api/report`。

### 输出长这样

```
方法            样本数   漏报率    误报率    平均耗时
规则             1070    60.0%     0.0%      2ms
端侧 TinyBERT    1070    --        --        --
DeepSeek         1070    --        --        --
```

### 三条要求

1. **可重复跑**：同样的数据，跑两次结果一样
2. **不覆盖原数据**：结果单独输出到 `demo/eval-calls/result-<日期>.json` 和 `.csv`
3. **记录参数**：每次跑的时候把规则版本号（`/api/health` 里有 `rules.version`）一起存进结果里

**优先级：脚本能跑起来 > 数据量大。** 先要一条能反复跑的流水线，数据以后可以补。

## 五、第三部分：找人录 30 通电话（跑腿活，越早问越好）

这件事最需要"求人"，所以早点开口。

**不是要真的被骗**，是**两个人两台手机互相打，照着诈骗话术念**：

- 15 通演诈骗（冒充公检法、冒充孙子、退款、投资、刷单各几条）
- 15 通正常（家人问候、快递、银行提醒、外卖）

**怎么录**：一部手机打电话，另一部开免提录音；或者用手机自带的"通话录音"功能。拿到的是真实 8k 音质、真实麦克风，这正是要测的东西。

**话术从哪来**：`D:\华为ict\外部数据集\fraudr1\` 里的文本随便挑，照着念就行。

**做完存哪**：`demo/eval-calls/audio/`，并在 `labels.json` 里登记。顺便写一句"谁录的、什么设备"，验收时有用。

如果实在凑不到人，**不要硬等**，先用 3.2 的两份数据集把基线跑出来，在报告里写明"真人诈骗通话样本待补"。
