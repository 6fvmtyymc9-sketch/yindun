## 四、三个坑记一下（写报告能用）

1. `enterprise_project_id: "0"` → RDS 创建报 `DBS.280433`。**这个账号不认 0，字段删掉就行**。
2. DCS 创建时可用区参数名是 **`az_codes`**，不是 `available_zones`。传错会报
   `DCS.4042 This AZ does not exist`——**报错说可用区不存在，其实可用区没错，是字段名错了**。
3. Redis 密码里有 `#`，写进 `REDIS_URL` 必须转义成 `%23`，否则会被当成 URL 锚点截断。
