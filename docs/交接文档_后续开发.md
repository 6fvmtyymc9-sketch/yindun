## 二、怎么跑起来

### 2.1 编译

| 平台 | 老人端 | 子女端 |
|---|---|---|
| Windows | `bash app/build2.sh`（原有） | `bash app/childapp/build_child.sh`（原有） |
| Mac | `bash app/build_mac.sh` → `app/build_mac/Yindun-debug.apk` | `bash app/childapp/build_mac.sh [服务器地址]` → `app/childapp/build_mac/ChildDemo-debug.apk` |

Mac 脚本打的是可调试包、用本机 debug 签名，适合开发测试；正式包仍用 Windows 脚本和 `yindun.jks`。

### 2.2 云端

```bash
cd cloud && npm install && node src/server.js
```

新增配置（见 `cloud/.env.example`）：

| 变量 | 作用 |
|---|---|
| `YD_ADMIN` | 管理员口令。设置后，`/api/config`、`/api/rules`、`/api/reset` 需带 `X-Yd-Admin`；不设置则只允许本机调用 |
| `SIS_*` / `ASR_*` | 语音识别（华为云 SIS 或 OpenAI 兼容接口），二选一 |
| `YD_TOKEN` | 可选，录音复盘接口的额外口令 |

配对数据存在 `cloud/data/pairs.json`（已忽略，不进仓库）。

### 2.3 测试

```bash
cd cloud
node test/run.js                 # 回归测试集：59 诈骗 + 40 正常
node test/run.js holdout.json    # 留出集：20 诈骗 + 15 正常
```

**改规则的规矩**：只对着 `cases.json` 调；`holdout.json` 只用来看真实效果，**不要对着它补词**。
新增样本请两边都加，诈骗和正常都要有。`app/assets/rules.json` 与 `cloud/config/rules.json` 必须同步修改。

### 2.4 模拟器注意事项

- 模拟器默认是**演示模式**（公开编号 `demo`），投影上的网页子女端直接能看到数据，无需配对。
  真机默认关闭演示模式，需要在向导里配对。
- 本机开发时，模拟器访问电脑上的云端用 `http://10.0.2.2:8080`。
- 模拟器建议 4 核、4GB 内存、使用电脑显卡（`-gpu host`）。1 核 + 软件渲染时红屏动效会严重卡顿。
- 录音复盘的演示方法见 `docs/通话录音复盘.md` 第七节（`demo/calls/call_test.sh`）。

## 四、建议接下来做的功能

### 4.1 亮点功能（评委印象深，优先做）

推荐先做前三个：一个打情感，一个讲社会价值，一个展示家庭协同，合起来是完整的"家庭 + 社会"反诈故事。

#### ① 亲情语音盾 ★★★

**是什么**：子女在子女端录一句自己的话（如"妈，别转钱，等我电话"），老人手机弹红屏时播放**女儿本人的声音**，代替机器合成音。

**为什么**：被骗的老人往往已被骗子"洗脑"，亲人的声音最能让人停下来。现场演示有情感冲击力。

**怎么做**：
1. 子女端：`MainActivity` 设置里加"录制提醒语音"，用 `MediaRecorder` 录 5～10 秒（需 `RECORD_AUDIO` 权限），上传到云端新接口 `POST /api/voice`（子女端凭证鉴权，按 elderId 存）。
2. 云端：存文件（如 `cloud/data/voice/<elderId>.m4a`），提供 `GET /api/voice`（老人端身份鉴权）。
3. 老人端：启动和每天定时下载到本地缓存；`Speak.play()` 现在会先找 `assets/voice/<key>.mp3`，找不到才用 TTS（`Speak.java` 第 116～144 行），改为**先找缓存的子女录音**。
4. 注意：拦截那一刻不能现下载，必须提前缓存。

#### ② 群体免疫号码网 ★★★

**是什么**：一位老人的通话被复盘判为诈骗后，该号码自动进入共享黑名单；其他老人再接到这个号码时，来电卡显示"该号码今日已被银盾判定诈骗 N 次"。

**为什么**："一人受骗，全网免疫"，体现群防群治的社会价值，数据可在答辩时展示。

**怎么做**：
1. 云端 `CallAudio.js`：判定 `high/block` 时调用 `db.addReport()`（`Db.js` 第 191 行），`reporter` 记为 `callaudio`。
2. 来电卡已经会调用 `/api/report/stats?number=` 查举报次数（`Acquaint.lookupReports`），把文案区分为"用户举报 N 次 / 银盾判定诈骗 N 次"。
3. 可选：被判定次数 ≥3 的号码，响铃时直接升级为红色提醒。
4. 注意隐私：只共享号码和次数，不共享通话内容。

#### ③ 子女远程干预 ★★★

**是什么**：子女端两个按钮——
- **提醒妈妈**：老人手机立即全屏显示"女儿正在联系您，请先不要操作"，并持续振动；
- **锁定转账 30 分钟**：这段时间内老人打开手机银行即弹红屏。

**为什么**：把子女从"事后知道"变成"实时参与"，形成家庭协同闭环。

**怎么做**：
1. 云端新接口 `POST /api/command`（子女端凭证）：存一条指令；老人端需要能收到——
   推荐老人端 `GuardService` 里开一条到 `/api/stream` 的长连接（复用子女端 `Hub.java` 的写法），收到 `type: "command"` 就执行。
2. "提醒妈妈"：复用 `Shield` 的全屏窗口，换一套文案和蓝色主题。
3. "锁定转账"：复用 `CallRecord` 的风险窗口（`riskUntil`），`Guard.onBankForeground` 已经会在窗口期内盖屏。
4. 子女端：首页汇总卡和预警详情页各加入口。

#### ④ 被骗套路 → 专属演练 ★★

**是什么**：通话复盘判为诈骗后，次日自动推送一局用同一套路改编的反诈演练："昨天那通电话的套路，陪您练一遍"。

**怎么做**：`Drill.js` 已支持按案例生成演练（`mode: 'case'`，第 408 行附近）。复盘判定后写入一条案例（脱敏后的关键语句 + 诈骗类型），`DrillAlarm` 次日提醒时带上这个案例 id。

#### ⑤ 一次事件的完整回放 ★★

**是什么**：子女端把一次诈骗的全过程串成一条时间轴：陌生来电 → 通话 5 分钟复问 → 收到验证码 → 打开银行 → 红屏拦截 → 自动呼叫女儿。

**怎么做**：老人端在 `Guard.startNewCall()` 生成通话 id，本次通话期间所有上报带上它；云端按 id 归组；子女端预警详情页按时间顺序展示同组事件。

### 4.2 能力补强

1. **扩大大模型复核**：现在只有本地 30～45 分的短信才送大模型（`SmsReceiver.java` 第 180 行）。留出集漏掉的大多是 15 分（只命中"陌生号码"）。
   可改为：陌生号码、长度超过 15 字、本地未达 warn 的短信都送复核。单次成本约 0.0003 元。
   上线前用 `holdout.json` 验证效果。
2. **断网补发**：`Notifier.postJson` 失败时写入本地队列，网络恢复后补发。
3. **国产手机保活引导**：按品牌（荣耀、华为、小米、OPPO、vivo）跳转自启动设置页，配图说明。

## 五、答辩口径备忘

- **两层防护**：实时拦截只看动作、不读内容、断网可用；挂断后复盘在老人授权下分析录音，只处理陌生号码，云端不存录音和全文。
- **规则效果如实报**：回归集漏报 0、误报 0；留出集漏报 60%、误报 0。说明规则负责"零误报的第一道拦截"，换说法的诈骗靠大模型兜底。
- **隐私与安全**：每位老人独立身份，子女端靠一次性配对码绑定，只读；管理接口只限本机或管理员。
- **适老化**：大字、高对比、一屏一件事；"认识/不认识"两个按钮一样大，不诱导老人选择；红屏没有关闭按钮，通话结束后自动关闭（另有 2 分钟兜底），骗子无法让老人"把窗口关掉"。
