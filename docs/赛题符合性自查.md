## 一、官方任务要求（原文）

赛题页对赛题1 写明的三条任务要求：

1. 选手**下载并使用华为云码道 CodeArts 代码智能体**；
2. **基于已有智能体和 Skills，进行关联 RDS、Redis 等华为云服务的快速开通创建**；
3. **基于已有智能体和 Skills，进行应用作品在华为云上的快速部署**。

并在「展示形式」中要求：云上部署，通过可视化 Demo 页面展示核心功能与交互流程；
**应体现华为云产品在需求理解、代码生成、项目构建、问题修复、部署上线等环节的使用价值**。

## 五、真正卡住的三个缺口

### 缺口 1（硬性）· RDS / Redis 不是用 Skills 开通的

**2026-11-19 19:30 状态更新**：真 RDS（MySQL 8.0 单机 2核4G `192.168.0.90`）与真 DCS（Redis 6.0 单机 1G
`192.168.0.138`）**已经开好并完成数据迁移，线上 `.env` 已切过去**，六表对数全等（1581/1225/10/0/2/0）。
**技术层面的缺口补齐了**（自建库 → 云数据库），但**赛题层面仍未满足**：

- 这两个实例是**队长侧用华为云 API（`rds/v3/instances`、`dcs/v2/instances`）直开的**，
  用的是项目自带的 `HwSign.js` 签名，**不是码道 Skills 开通的**，没有「智能体开通云服务」的过程记录。
- 赛题第 2 条的措辞是"基于已有智能体和 Skills，进行关联 RDS、Redis 等华为云服务的**快速开通创建**"，
  验收看的是**过程**，不是"有没有实例"。官方 Q&A 已明说：仅用了华为云服务、没按要求用码道，不算符合。

**补齐办法（按性价比排序）**：
1. **用码道 Skills 再开一个最小规格实例并录屏，录完立即释放**（Redis 0.125G 或 RDS 基础版最小档，
   按小时计费，几毛钱）。录屏里要能看清：自然语言指令 → Skills 调用 → 创建中 → 实例出现在列表 → 删除。
   **这是唯一能真正补上第 2 条的做法**。
2. 退一步：用 Skills 对已有实例做"查询/变更配置"，能证明 Skills 通了云服务，但"创建"二字说服力弱，
   只能算部分符合。
3. 反面做法：拿现在这两个实例充当 Skills 的成果——**材料与过程不符，属事实性不准确，风险高，不要做。**

详细参数与踩坑记在 `docs/RDS_DCS_开通记录_20261119.md`，交给甲的信息在 `docs/交接_甲_RDS与Redis_20261119.md`。

### 缺口 2（硬性）· 部署是手搓的，不是 Skills 一键部署

官方在赛题页直接给了 Skills 一键部署的示例文档链接（`gitcode.com/.../auto-deploy-case-study.md`）。
现在的部署路径是本地 `scp` + 服务器 `systemd`，属于"能跑但过程不合规"。

**补齐办法**：用 Skills 重新走一次部署（哪怕服务已经在跑，也可以重新走一遍并把过程录下来），
重点是产出**可复现的部署记录**，而不是"我上去手动改了两行"。

### 缺口 3 · ~~项目构建环节是空白~~ → **2026-11-19 已补齐**

曾经是五环节里唯一完全没有智能体参与的一项。2026-11-19 16:51 把
`app/build.gradle`、`app/build2.sh`、`app/AndroidManifest.xml`、`deploy/install.sh`（含 systemd 单元生成）
连同 `settings.gradle` / `gradle.properties` / wrapper 配置一起送审，10 条意见逐条判完。

**顺带捞出的两个真缺陷，都不是码道提的**（是顺着它「做不了清单」回看构建入口时发现的）：

- `build.gradle` 缺签名配置时直接 `throw GradleException`，而 `local.properties` 在 `.gitignore` 里
  → **评委 clone 下来第一条命令必然失败**，且与 README 写的「没密钥就用 debug 签名」正好相反。
  已改为降级 + 醒目提示，实测有/无 `local.properties` 两种状态都能 BUILD SUCCESSFUL。
- README 构建小节缺三件必须说清的事：首次构建要联网、`ANDROID_HOME` 要设、
  `sdk.dir` 也是 `local.properties` 的一项。已补，并追加一条「代码必须保持 Java 8 语法兼容」（双构建的前提）。

改完 8 项验证全过：`bash -n` 语法、`env.js` 取首/覆盖语义三例、`build2.sh` 实跑 47.2M、
Gradle `--offline` 43s、两条路线 `.so` 压缩方式一致（全 DEFLATED）、双向覆盖安装三次 Success、
`versionCode/versionName` 一致、装完 `am start` 主界面四项防护全开。
