## ⚠️ 提交前必须先决定的一件事：Demo 地址能活多久

材料里写了 `http://123.249.25.139:8080/`，评委看材料时会点。三条规矩：

1. **ECS + 弹性 IP 不能释放**，否则地址变 404，比不写更糟
2. **RDS / DCS 可以释放**（省约 21 元/天），但释放后 `/api/health` 会报 `rds:false` `redis:false`。
   演示页正常交互不依赖数据库，**但如果页面上显示了"云端存储已连接"之类的状态灯，会变红**
3. 若要彻底省钱又保面子，另一个选择：材料里只写「云端 Demo 页面已部署在华为云 ECS，可按需提供访问地址」，
   不写具体 IP。但这与赛题"通过可视化 Demo 页面展示"的字面要求贴得没那么紧，取舍自己定
