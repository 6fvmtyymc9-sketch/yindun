## 05 项是怎么补到的（不是改阈值造假）

触发条件只有一个：**陌生号通话满 5 分钟**。代码里对模拟器有 20 倍速
（`Guard.java` 的 `IS_EMULATOR`：真实 1 秒判作 20 秒喂给判级，显示给人的时长仍是真实值），
所以模拟器上真拨约 **15 秒**就走到阈值，不需要陪聊 5 分钟。做法：

```bash
adb emu gsm call 19900001234          # 陌生号码来电
adb shell input keyevent KEYCODE_HEADSETHOOK   # 接听
adb logcat | grep "第二次询问"          # 等这行日志
adb exec-out screencap -p > 05.png
```

本次实测日志（2026-11-20 23:46）：

```
I YinDun : 通话开始 who=stranger num=19900001234
I YinDun : 通话满 5 分钟 → 第二次询问（持续振动，点按钮才停）
I YinDun : 级别升到 watch（触发源=tick）原因=陌生号码通话时间偏长
I YinDun : 通话复问卡已弹出：19900001234（持续振动，点按钮才停）
I YinDun : 持续振动已开始（振 400 / 停 1200，循环），不自动停
```

⚠️ **这张图的边界，用的时候要如实说**：

- 背景是**系统拨号盘**，不是通话界面——模拟器（无窗口模式）不渲染 InCallUI，
  卡片本身是银盾的悬浮窗，所以背景上是哪个页面都正常。真机上它盖在通话页之上。
- 卡片上的「5 分钟」是**判级时长**（20 倍速换算），状态栏没有通话计时可比对，看不出来，但这不是造假：
  走的是代码里本就存在的模拟器倍速，**没有临时改阈值**。
- 真机版仍可补（拨陌生号等真 5 分钟，用另一台手机拍），补到就替换本图，图注改为真机实拍。

**旁证仍在**：`09-child-call-list-5min-recheck.png` 里 21:46 那条
「妈妈确认通话对方为熟人（通话已超过 5 分钟）…妈妈选择了"认识"」，
是 11-17 那次回归里复问卡触发并推到子女端的留痕，和本图互相印证。
