## 与模拟器截图的区别

- 模拟器截图（`docs/img/demo/`）是**系统截图**，像素 1080×2280，状态栏为 AOSP 原生样式，无手机边框。
- 本目录是**相机拍的屏幕**，像素 1280×1707，能看到机身、手、反光、划痕、拍摄角度造成的轻微梯形变形。

对外材料里两者**不可混用图注**：模拟器图写"Android 11 模拟器"，本目录写真机实拍。

## 补拍方式（不需要连电脑）

用另一台手机对着屏幕拍即可，本批就是这么来的。要拍的三张：

1. 真机拨陌生号 → 等满 5 分钟 → 复问卡出现时拍（这张最要紧，补齐 demo 第 05 项）；
2. 挂断后自动补拨 → 进入通话页时拍；
3. 子女端 App（另一台装了子女端的手机）→ 时间线复盘页 / 告警列表页拍。
