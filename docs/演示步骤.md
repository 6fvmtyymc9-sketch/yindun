# 现场演示脚本

全程约 5 分钟。按顺序走，每一步都有预期结果，对不上就看最后一节排障。

---

## 零、开场前 3 分钟（双机准备）

演示要两台手机并排：**左边老人机**（银盾）、**右边子女机**（银盾家人）。

### 1. 启动两台模拟器

双击 `D:\Android\启动双模拟器.bat`。

它会依次起 `yindun30`（老人）和 `yindun_child`（子女），等两台开机完成，再统一关掉自动息屏。
**两个黑窗口都要留着**，关掉哪个哪台手机就没了。

> 内存吃紧时先退出 Android Studio —— 它一个人占 1.2 GB，两台模拟器各占 1.5 GB。

### 2. 确认云端在线

```bash
curl http://<你的服务器>:8080/api/health
```

返回里 `ok: true` 才算好。顺手看一眼 `rules.version` 是不是 `3.3`。

### 3. 清场（两台都要）

```bash
for P in 5554 5556; do
  adb -s emulator-$P shell input keyevent KEYCODE_HOME
  adb -s emulator-$P shell input keyevent KEYCODE_ENDCALL
  adb -s emulator-$P shell input keyevent KEYCODE_WAKEUP
done
```

### 4. 确认两端都活着

- **老人机**：打开银盾，首页三只眼睛全是绿灯「在看着」
- **子女机**：打开「银盾家人」，顶栏右上角是**绿点 + 实时连接**

子女机显示「已断开，重连中」就是云端连不上，先查第 2 步。

## 一、微信诈骗（1 分钟，最直观，建议先演这个）


1. 打开**微信壳**（应用抽屉里，绿色聊天图标）
2. 约 1.2 秒后**第一条**消息自动到达：
   `小李啊，我是社保局这边负责您片区的，工号 0371`
   → **不弹浮条**。这是 watch 级（50 分，S1 套近乎），正常，专门用来证明不是"什么消息都报警"
3. 点底部绿色的「**演示：模拟收到下一条消息**」
4. 第二条到达：`系统显示您的医保卡被他人冒用，涉及一笔 1.8 万的违规报销`
   → 屏幕**下方**弹出橙框浮条：**⚠ 疑似诈骗信息 / 请谨慎点击短信链接**
5. 再点两次：`先不要告诉家里人`（S3 隔离，high）、`点 t.cn/Yb9K2 认证，逾期注销`（含链接，warn）→ 都弹

**讲解点**：浮条从下方弹是有原因的——顶部被微信自己的通知横幅占着，贴上边就会被整个压住。
浮条没有声音、没有按钮、9 秒自动消失，因为骗子一句"把那个弹窗关掉"就能破防。

## 二、短信诈骗（1 分钟）

1. 回桌面
2. 注入一条真实短信：

```bash
adb emu sms send 106901234567 "【ETC】您的通行卡已停用，请点 t.cn/Etc7 认证，逾期注销"
```

3. 预期：状态栏弹出系统短信通知（真通知），1.2 秒后屏幕下方弹出银盾浮条

**讲解点**：这条不是 App 里预置的剧本，是真短信、真通知、真判定。判定命中
`逾期/已停用/注销/点/ETC/含链接`，得 75 分（high）。同样的内容换成"快递已放丰巢，取件码 8832"就是 0 分不弹。

可以再补一条对照：

```bash
adb emu sms send 95588 "【工商银行】您账户入账 5000 元，余额 12000 元"
```

→ 不弹。反例词把分数压下去了。

## 三、通话（1.5 分钟）

1. 回桌面
2. 注入陌生来电：

```bash
adb emu gsm call 13900001111
```

3. 响铃界面出现，屏幕上方弹响铃卡，**同时**子女端收到「妈妈接到陌生号码来电」
4. 在响铃卡上点「**不认识**」
5. 接通。等通话满 5 分钟（演示环境有 ×20 倍速，实际约 15 秒）→ 全屏复问卡：
   **这通电话已经聊了 5 分钟** / **电话那头，是您认识的人吗？**
   手机开始**持续振动，点按钮才停**
6. 再点「不认识」→ 振动停，自动拨给子女（屏幕变成通话界面，这是设计行为）
7. 挂断（`adb shell input keyevent KEYCODE_ENDCALL`）

**讲解点**：复问卡不是到点就走，得点一下才消失——因为老人被骗子牵着走的时候，
会本能点"认识"来结束弹窗，这一下反而是最后一次刹车机会。

---

## 四、银行拦截（1 分钟，压轴）

**注意：必须在通话中打开银行，单独开银行不触发。**

1. 先注入一通电话并接听：

```bash
adb emu gsm call 13900001111
adb shell input keyevent KEYCODE_HEADSETHOOK
```

2. 保持通话，上滑桌面 → 打开应用抽屉 → 点「中国工商...」（图标是蓝色安卓小机器人，因为它是壳）
3. 2 秒内出现**全屏红屏**：「先别转钱 / 这通电话可能是骗子」

```bash
adb emu gsm cancel 13900001111
```

4. 挂断骗子的电话 → 3 秒后红屏自动撤掉；如果一直不挂，2 分钟后兜底撤屏
5. 红屏期间 6 秒无人操作会自动拨给子女

**讲解点**：红屏没有关闭按钮是故意的。骗子只要说一句"你把那个窗口关掉"，
所有提示就白做了。撤屏只有两条路：挂断电话，或者点「打给女儿」切走当前通话。

## 五、子女手机（30 秒）

右边的子女机上装的是「银盾家人」App，不是网页。它连的是云端同一条 SSE 实时流。

**每一次告警都会同时发生三件事**：

1. 子女机**响铃 + 振动 + 弹通知**（App 在后台也照响，靠前台服务保活）
2. 时间线顶部**插入一张卡片**：等级色条、标题、时间、来源标签
3. 概览数字往上跳（`最近 N 条提醒`）

卡片上的标签是**来源**：`微信` / `短信` / `电话` / `转账`。
高危（high）和阻断（block）的卡片还会多一个绿框，那是云端大模型补的一句人话，例如
「妈妈正被冒充领导的人要求瞒着家人转账」。

**如果想让子女机上的标题更具体**，长按子女机顶部「银盾 · 家人守护」那一行，
可以改服务器地址和老人编号，改完自动重连。

**断线表现**：顶部状态点变红、文字变「已断开，重连中」，点一下立即重试（不等 3 秒）。

> 也可以在电脑浏览器里打开同一套网页版子女端（`http://<服务器>:8080`），
> 投影时字更大。App 和网页看的是同一份数据，不是两套系统。

## 六、排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 浮条不弹 | 没有悬浮窗权限 | 设置 → 应用 → 银盾 → 悬浮窗 打开 |
| 浮条被通知盖住 | 旧版本浮条贴在顶部 | 升级到当前版本（改为从下方弹） |
| 第二条消息不弹 | 10 分钟去重，同一条内容只判一次 | 重启微信壳，通知时间变了就重新判 |
| 通话满 5 分钟没反应 | 屏幕休眠或 App 进程被杀 | 检查首页是否还在「在看着」 |
| 银行红屏不出现 | 不在通话中 | 拦截条件是"通话中 + 打开银行"，两条都要满足 |
| 子女端不跳转 | 网页没刷新 | F5 一次 |
| 子女端一片空白但服务在线 | 历史只取最近 20 条，可能全被清了 | 重新触发一次告警 |
| 模拟器黑屏 | 屏幕休眠 | `adb shell input keyevent KEYCODE_WAKEUP` |
| 子女机一直「连接中」 | 云端连不上，或手机没网 | 点一下顶栏重试；确认 `curl /api/health` 有响应 |
| 子女机收不到但网页能收到 | 子女机装的还是旧包 | 重装 `release/ChildDemo.apk` |
| 子女机响铃但没弹通知 | Android 13+ 通知权限没给 | 系统设置 → 应用 → 银盾家人 → 通知 打开 |
| 两台模拟器一起起不来 | 内存不够 | 退出 Android Studio，只留两个模拟器窗口 |
| 子女机时间差 8 小时 | 模拟器时区是 UTC | `adb -s emulator-5556 shell "cmd alarm set-timezone Asia/Shanghai"` |

## 七、答辩时可能被追问的三个问题

**问：这套东西能拦住多少？**
答：拦不住通话本身（Android 不给挂断权限），拦的是"钱出门"这一步——盖屏、拦银行、
通知子女。判定用的是可解释的规则引擎，每条分数能摊开给人看，不是一个黑盒概率。

**问：词库靠人工维护，骗子换个说法怎么办？**
答：两层。词库之外还有链接形式识别（不看词，看有没有可点网址）和发送方加权（陌生号码本身加分）。
另外 30–45 分这个灰区会送大模型复审，模型只能升级不能降级，防止误判把警报撤掉。

**问：这些演示是不是写的假数据？**
答：短信是真进系统库的真短信，通知是真通知，判定是引擎真算出来的，浮条是真悬浮窗。
只有"谁按了发送键"是模拟的——换成另一部手机发就行，代码一行不改。
微信和银行是壳，但壳只负责产生真实的事件（一条真通知、一个真前台应用），
壳里一行判定逻辑都没有。
